Selected embedded work

Case Studies

A few examples of embedded firmware, hardware, wireless, and product engineering work we have supported.
Some projects are anonymized due to client confidentiality.

Energy-Harvesting Board Firmware

Firmware for an ultra-low-power energy-harvesting board, focused on wake behavior, power-sensitive operation, and reliable event handling.

Z-Wave Long Range Low-Power Device Work

Low-power wireless device work involving Z-Wave / Z-Wave Long Range behavior, wake-on-event operation, timing, radio energy, and protocol-level constraints.

Home Assistant BLE Device Integration

BLE device integration work for commissioning, discovery behavior, device state mapping, and user-facing reliability.

Zephyr RTOS Firmware Bring-Up

Zephyr-based embedded firmware work involving device tree, Kconfig, drivers, BLE, work queues, timers, and board-specific configuration.

nRF54 / Zephyr Leak Sensor Firmware

Zephyr-based firmware work for a Nordic nRF54 low-power leak sensor, including sensor events, BLE advertising, build configuration, and embedded debugging.

ESP32 Spark Controller Firmware

ESP32-based controller firmware for microsecond-level switching, timing control, and hardware output coordination.

Board Bring-Up and Hardware Debugging Support

Peripheral validation, sensor interfaces, power issues, communication buses, and firmware/hardware integration.

STM32 Timer / DAC / DMA Control Firmware

STM32 firmware using timers, DAC triggering, DMA, event timing, and hardware-timed control behavior.

Low-Power Measurement and Debugging

Power profiling and firmware optimization involving sleep modes, radio timing, current measurement, wake-up behavior, and battery-sensitive operation.

Ultra-Low-Power Zigbee Green Power Firmware

Zigbee Green Power firmware on Silicon Labs hardware for ultra-low-power button devices and energy-sensitive wireless operation.

Industrial HVAC Controller Hardware

HVAC controller board with opto-isolated inputs, Darlington array outputs, embedded control logic, and hardware validation support.

BLE Advertisement Scanner on nRF52840

Custom BLE scanner firmware on Nordic nRF52840 for capturing advertisements, RSSI, manufacturer data, and wireless device behavior.

BLE Mesh Home Automation Firmware

BLE Mesh based home automation firmware work involving wireless control, device communication, and embedded product integration.

ESP32 Facial Recognition & Thermal Measurement System

ESP32-based facial recognition and thermal measurement system with camera integration, local processing, and web-based monitoring.

ESP32 LED Strip Controller with BMS Support

ESP32-based LED strip controller with integrated BMS/charging circuit support, embedded control firmware, and hardware integration.
